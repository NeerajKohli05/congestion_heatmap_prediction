Why this problem matters

Integrated circuits contain many cells connected by metal wires. When local routing demand is high relative to available routing capacity, congestion can make physical design more difficult. A spatial estimate can help engineers inspect potential hotspots earlier in the design process.

Project workflow

1. Prepare data. CircuitNet N14 provides precomputed placement-related maps and early-global-routing utilization maps. The project resizes and packages them into model-ready samples.

2. Train the model. A Residual Attention U-Net learns the relationship between six placement maps and two routing-utilization maps.

3. Predict. The web app loads a prepared sample, sends its six input maps through the trained model, and generates horizontal and vertical predictions.

4. Compare. For samples that include reference targets, the app calculates metrics and displays reference, predicted, and absolute-difference heatmaps.

Model inputs and outputs

Each prepared sample is represented on a 128 × 128 grid. The model receives six spatial channels and predicts two continuous early-global-routing utilization maps.

Model approach

Architecture. The Residual Attention U-Net uses an encoder-decoder structure to learn both broad chip-level patterns and local congestion features. Skip connections preserve spatial detail; attention gates help focus on informative regions.

Training objective. The code combines hotspot-weighted Huber error, structural similarity, and correlation loss. This encourages accurate utilization values and spatial patterns, while giving higher weight to congested regions.

Dataset and evaluation

The prepared multi-design dataset contains 192 samples: 96 NVDLA-small and 96 Vortex-small placement variants. The training split uses 164 samples; 28 samples are used for validation.

The current evaluation script reuses those same 28 validation samples as its reported “test” set. Therefore, the saved scores are validation results, not an independent final test. An untouched test set is needed for a separate final performance claim.

What the dashboard shows

The Analysis page lets a user select one of the prepared samples, run inference, inspect the input channels and compare predicted utilization with the sample’s reference maps. PCC measures spatial pattern agreement; MAE and NMSE measure error; hotspot F1 measures overlap of the top-utilization regions.

Scope: This repository is a prediction prototype using prepared CircuitNet maps. It does not currently accept raw Verilog and automatically run synthesis, placement, or routing. Predictions estimate utilization; they do not replace an EDA router or guarantee routing success.

What “best RTL” would mean

The congestion model cannot judge raw RTL directly: it only sees placement feature maps. Each RTL candidate must first pass verification, synthesis and placement. The predictor can then estimate routing utilization for that placed candidate. A system could rank candidates against user-defined limits such as timing and area, alongside predicted congestion; the current model does not itself predict timing or power.

Steps needed to reach this roadmap

1. Build a robust extractor. Convert real placed DEF/LEF and technology data into the exact six channels expected by the trained model.

2. Add features-only inference. A new design has no reference target before routing, so prediction must work without target maps or target-based metrics.

3. Validate beyond the current split. Create a truly independent test set and test across new placements, designs and compatible technology conditions.

4. Integrate external tools safely. Add managed synthesis/placement jobs, candidate tracking, resource limits and user review before any automated ranking.

Current project boundary

Implemented today: prepared CircuitNet sample loading, model inference, heatmap visualization and target-based comparison. Proposed only: RTL generation, RTL verification, synthesis, floorplanning, placement, automated feature extraction for arbitrary designs, and best-candidate selection.
